# BBM — Wear Your Vibe

A responsive multi-page streetwear storefront starter.

## Included
- 20 HTML pages with shared navigation and footer
- Responsive CSS design system
- Product catalogue with sample INR prices
- Search, category filtering and sorting
- Product detail pages with size selection
- Browser-local cart and wishlist
- Demo checkout, contact, newsletter and tracking interactions
- Basic per-page title and meta description

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or run a local static server.
3. Replace sample products, images and all `[confirm]` business details.
4. Test on mobile and desktop.

## Important limitations
This is a frontend demo/storefront starter, not a production-ready commerce backend.
- Cart and wishlist use this browser's localStorage only.
- No real accounts, payment collection, order creation, inventory sync, shipping or email delivery is connected.
- Forms display demo feedback only.
- Legal policy pages are starter placeholders and require review.
- Product photos and product details are illustrative; confirm image rights, actual products, pricing, sizes and claims before commercial use.

## Suggested production upgrade
Connect a secure backend and database, authentication, payment provider, shipping provider, email service, admin product management, server-side validation, security headers, backups, monitoring, analytics and tested deployment.
